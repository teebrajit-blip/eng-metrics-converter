# engineering-metrics-converter

A professional utility for structural and mechanical unit conversions.

## Features
- **Double Verification**: Built-in input type checking.
- **Precision**: Rounded to 4 decimal places.

## Usage
```javascript
const { convertForce } = require('your-package-name');
console.log(convertForce(100, 'N', 'lbf')); // 22.48
